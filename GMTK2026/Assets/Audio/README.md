# Настройка звука

1. Откройте `SoundConfig.asset`.
2. Назначьте `Menu Music` и `Game Music`.
3. В `Sounds` раскройте нужное событие и добавьте один или несколько клипов в `Clips`.
4. При необходимости настройте громкость, диапазон pitch, 2D/3D, cooldown и число голосов.
5. Добавьте prefab `SoundManager` только в стартовую сцену. Между сценами он сохраняется автоматически.

Пустые события безопасно пропускаются. Для нескольких клипов вариант выбирается случайно при каждом проигрывании.
